# Exercise 36: The capstone is the exercise

There is no separate exercise for this lesson either. Shipping is the exercise.

**Milestone checklist for this lesson:**

- [ ] Deployment checklist (Lesson 36, Step 1) worked through, every box honestly checked, with the demo run verified from a fresh clone in a clean folder.
- [ ] Project README written from `project-readme-template.md`, including real demo output and the full harness output.
- [ ] Repo confirmed public by opening it in a private or logged-out browser window.
- [ ] Showcase PR opened against the course repo: one row, format per `showcase/README.md`, nothing else touched.
- [ ] `completion-checklist.md` copied into my fork and completed.
- [ ] One public post written about the build: what it does, what the eval suite caught, what comes next, with links to the project and the course.

When the showcase PR merges, you have finished Agentic AI for Beginners. The checklist in this lesson is the last page of the course, and the first page of whatever you build next.
