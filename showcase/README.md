# Capstone showcase

Finished capstones from learners of Agentic AI for Beginners. This table is the course's completion artifact: no certificates, just working projects anyone can open, run, and inspect.

## How to get your capstone indexed

1. Finish the capstone (Lessons 34 to 36). Your project must be in a public repository of your own, with a README that says what the assistant does and how to run it.
2. Fork this repository and add **one row** to the table below: your name or GitHub handle, a link to your capstone repository, and one line describing what your assistant does.
3. Open a pull request titled `Showcase: <your handle>`. Small, single-purpose PRs like this merge directly under the course's [two-tier contribution rule](../CONTRIBUTING.md); you do not need to open an issue first.
4. A maintainer checks that the link works and the repository is a real capstone (it runs, or its README honestly says what state it is in). Working beats polished.

One row per learner. If you rebuild your capstone later, update your row with a second PR.
