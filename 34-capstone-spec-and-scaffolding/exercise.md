# Exercise 34: The capstone is the exercise

There is no separate exercise for Lessons 34 to 36. The capstone build is the exercise, and it is graded by the acceptance checklist in Lesson 34 and the eval suite you build in Lesson 35, not by a hidden answer key.

**Milestone checklist for this lesson:**

- [ ] Fork the course repo and copy `capstone/` into your own project repo.
- [ ] Run `python3 tests/smoke_test.py` on the untouched scaffolding and see it pass.
- [ ] Read the full spec in the lesson README and write, in your project README, the list of spec sections in your own words. If you cannot restate a section, reread it before coding.
- [ ] Decide and record: heuristic extractor or model-backed extractor, and why.
- [ ] Implement `capture()` and re-run the smoke test.

When all five boxes are checked, move to Lesson 35. Bring your questions to the course Discussions rather than sitting stuck; stuck-and-silent is the only real failure mode in a capstone.
