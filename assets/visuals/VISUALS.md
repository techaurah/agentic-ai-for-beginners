# Visual guide

Every core idea in this course has a diagram. They are drawn in one style so
the shapes stay familiar: navy boxes are the main actor or step, light boxes
are supporting steps, amber boxes are gates where a human or a safety check
decides. Each diagram also lives inside the lesson it belongs to.

|---|---|---|
| [course-map.svg](course-map.svg) | The whole course on one page: 11 modules, one arc, one capstone | README |
| [agent-vs-chatbot-vs-workflow.svg](agent-vs-chatbot-vs-workflow.svg) | How to tell an agent, a chatbot, and a workflow apart before building the wrong one | Lesson 01 |
| [how-llms-work.svg](how-llms-work.svg) | Tokens in, probabilities out: why models forget, drift, and cost what they cost | Lesson 03 |
| [agent-loop.svg](agent-loop.svg) | Perceive, think, act, observe: the loop inside every agent framework | Lesson 09 |
| [tool-calling-flow.svg](tool-calling-flow.svg) | The model asks, your code acts: who runs tools, and where MCP fits | Lessons 12 and 14 |
| [memory-types.svg](memory-types.svg) | Context window, short-term store, long-term memory, and when each applies | Lessons 15 to 17 |
| [rag-pipeline.svg](rag-pipeline.svg) | Documents to chunks to retrieval to an answer with citations | Lessons 18 to 20 |
| [multi-agent-handoffs.svg](multi-agent-handoffs.svg) | Roles, explicit handoffs, and the review gate between agents | Lessons 21 and 22 |

Diagrams are generated by [generate_visuals.py](generate_visuals.py) so the
set stays consistent. Edit the script, rerun it, and commit the SVGs it
writes. Every use carries descriptive alt text, so screen-reader learners
and search engines get the same content as sighted readers.
